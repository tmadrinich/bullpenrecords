01 / Logos

The mark

Always the SVG file, never retyped or redrawn. Minimum width 160px, which is the size used in the header. The file carries its own clear space. No stretching, recoloring, outlines or shadows. A dark overlay goes under it if it ever sits on a photo.

The B · small spaces only

The B stands in for the full logo only where the wordmark can't be read: browser tabs and home-screen icons. Everywhere else, use the full logo.
